Claude Code theme · Terminal.app profile

Jack & Jill for the terminal

The monochromes and the magic six, spent on a terminal: sixteen ANSI slots, seventy-two Claude Code roles, and a contrast floor that every one of them is measured against rather than assumed to clear, derived from lib/brand.ts, so the brand stays the single source of truth.

14/16 slots are literal brand hexes on Black 78 + 78 pairs measured 0 below floor AA 4.5 text · 3.0 UI

Two grounds

The magic six were lit for a dark ground, which is why almost nothing has to move on Black and almost everything does on Paper. Hue is the source of truth there and lightness is derived, which is the move autoBaseColor and tierLighting already make in the studio. On Paper the bright tier is the darker one: on a light ground, stronger means more ink.

The ink is Clay, not white

Pure white on near-black measures 20.87:1, which is the ceiling and reads like one: clinical, and with nowhere for emphasis to go. Body text takes Clay #f2f2eb instead, the brand's own warm off-white, at 18.56:1 — still four times the AA floor — and pure White is kept for bold, so the hierarchy climbs rather than starting at the top. Below the body it steps down through Dove and two derived greys.

The status line, and the rest of the terminal

Claude Code runs a command and prints its stdout under the prompt, so the strip is a shell script emitting slot numbers, never hexes — it follows the ground without being told which one is on. Context is drawn as mass rather than a number alone, and turns Honey under 30% and Flame under 15%.

Everything else in the terminal reads the same sixteen slots, so it comes along for free once pointed at them: LS_COLORS (directories Periwinkle, links Sky, executables Emerald, archives Coral, media Orchid, a broken link Flame), fzf by slot number, less so man pages stop being blue on black, and git's own color.*. bat and delta both have an ansi mode that draws with the terminal's slots, which is better than a generated theme for each: they inherit the brand exactly and flip ground with it.

What each slot is spent on

Every accent role points at a slot rather than carrying a colour of its own, because Terminal.app renders its own palette exactly and approximates a 24-bit value into its 256 cube. Only the surfaces (message grounds, selection, the diff beds) are written as rgb(), where a shade of a shade is imperceptible and a slot reference would collide with the dim text living in the same slot.

The floors, and what came closest to them

4.5:1text roles
3.0:1borders, dims, spinners
4.5:1the glyph under the cursor
4.5:1inverse ink on a chip

A chip is an accent block with inverse ink on it, so every accent is squeezed from both sides: dark enough to read on the ground, light enough to carry white. On Paper those two demands very nearly meet, and the tightest is 4.77:1, which is exactly the kind of thing that only shows up if you measure it. The block cursor answers to the text floor rather than the UI one, because Terminal draws the character beneath it in the ground colour.

Putting it on

  1. Install the plugin

    The theme travels as a Claude Code plugin, so nobody copies files. It arrives as two pinned entries in /theme, namespaced to the plugin.

    /plugin marketplace add jack-and-jill/jj-brand
/plugin install jj-brand@jack-and-jill

  2. Run the terminal kit once

    The half Claude Code cannot set: the sixteen slots, the ground, the cursor, the selection, the status line and the shell palette. It backs up everything it touches, keeps a status line you already have, and never overwrites a git colour you set yourself. --all adds the Dock toggle and the flashing cursor.

    ~/.claude/plugins/cache/jack-and-jill/jj-brand/1.0.0/install.sh --all

  3. Pick it, and reload the shell

    /theme        # Jack & Jill
exec zsh      # for LS_COLORS, bat, fzf, less

  4. Not on Apple Terminal?

    The same palette is generated for Ghostty, iTerm2, Kitty, Alacritty, WezTerm and VS Code's integrated terminal. One include line each; the kit prints the right one for the terminal you are in.

    kit/dist/{ghostty,iterm2,kitty,alacritty,wezterm,vscode}/

  5. Flipping ground

    The Dock icon, or /jj-brand:ground from inside Claude Code, or jj-ground.sh from any shell. All three do the same thing: every open window at once, then Claude Code's theme file, in that order — so a terminal that refuses to change leaves the theme alone rather than letting the two disagree.

The cursor changes colour on every blink

Terminal has no dynamic-colour escape code (no OSC 12), but cursor color is a settable per-tab property in its scripting dictionary, so it can be driven from outside. A background agent walks the magic six at the blink cycle, one change per cycle, so every flash differs from the one before it. These are the real hexes at full saturation, on both grounds.

Two honest limits. Terminal's blink phase is not observable from outside, so the switch drifts within the cycle and sometimes lands mid-flash rather than in the dark half. And the true colours were lit for a dark ground: on Paper they measure between 1.31 and 2.36:1, so the cursor is faint there and a glyph beneath a block cursor is hard to read. A re-lit set that clears 4.5:1 on Paper ships alongside, unused unless the agent is started with lit.
